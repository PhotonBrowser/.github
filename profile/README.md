# Photon Browser

We're building **Photon**, an open-source browser with a native interface and a browser engine based on [Ladybird](https://ladybird.org/).

Photon is still early in development. Right now, we're focused on the macOS browser, improving the browsing experience, and making it easier for people to build and contribute. Linux support is also a work in progress.

**Explore the project:** [Photon](https://github.com/PhotonBrowser/photon) · [Browser engine](https://github.com/PhotonBrowser/photon-engine) · [Contributing](https://github.com/PhotonBrowser/photon/blob/main/CONTRIBUTING.md)

If you're curious about what we're building, have an idea, or want to help out, you're welcome here.
